🛸 关于本站 / About

本站基于 美国战争部 (Department of War) 2026-05-08 公开的 UFO/UAP 解密档案 Release 01 （https://www.war.gov/UFO/） 构建。原始档案共 161 条记录、307 个文件（PDF/视频/图像），约 3.7 GB。

数据处理流程

  1. 下载：通过 Akamai TLS 指纹绕过下载全部 161 条记录与 28 个 DVIDS 视频。
  2. OCR：72 个扫描影像 PDF 共 3222 页，使用 Tesseract (CPU) + EasyOCR (GPU RTX 3080 Ti) 混合管线， ~12 分钟完成。
  3. 事件抽取：从 CSV 清单 + 自动正则匹配（Box7 检查表 / FBI 备忘录 / USAF 1946-49 公函 / COMETA 罗斯威尔年表）抽取出 269 条带日期+地点的事件，地理编码 175 条到本地图。
  4. 人类活动 heatmap：来自 GeoNames cities15000 数据集， 33,604 个人口 ≥15,000 的城市，按 log10(人口) 加权。

如何添加新事件批次 / How to add new event batches

本站设计为可扩展。后续若有新的 UAP Release（如 Release 02），只需：

  1. 将新事件整理为 JSON，结构如下：
{
  "batch_id": "002",
  "batch_name": "DoW UFO/UAP Release 02",
  "release_date": "2026-XX-XX",
  "source_url": "https://www.war.gov/UFO/",
  "events": [
    {
      "date_iso": "1947-07-04",                // 必需：YYYY-MM-DD
      "date_raw": "4 July 1947",               // 原始日期字符串
      "location": "Roswell, New Mexico",       // 必需：与 geocode.json 中的键匹配
      "agency": "FBI",                          // 报告机构
      "type": "PDF",                           // PDF / VID / IMG
      "title": "事件标题或正文摘要",
      "source": "FBI Case File ..., p.XX",
      "file": "原始文件名.pdf",
      "page": 70,
      "archive_url": "archives/pdfs/原始文件名.pdf"  // 详情页"打开原始档案"链接
    }
  ]
}
  1. 把 JSON 文件放入 data/events/ 目录，如 batch_002_release_02_2026-XX-XX.json
  2. 在 data/manifest.json 的 batches 数组中加入新文件名
  3. 如果有新地点，更新 data/geocode.json，添加 {"地点名称": {"lat": 33.39, "lon": -104.52}}
  4. 把原始 PDF / 视频 / 图像放进 archives/pdfs/ 等目录（或建符号链接）
  5. 刷新页面即可看到新事件
更简便的批量添加方式：你可以重跑 build_site_data.py（生成器脚本）， 它会自动从 events_v2.json 重建所有数据文件。如果增加了新的源文件， 也可以扩展 extract_events_v2.py 添加新的源抽取器。

本地启动

由于浏览器安全限制，需通过 HTTP 服务器访问，不能直接双击打开 HTML：

cd ufo_site
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000

已知限制

  • 未地理编码事件 (94 条)：OCR 噪声让部分地点名称不可识别（如 "Iake 01ty, Sonttlo Maeh"）；这些事件未显示在地图上。
  • 位置精度：精确到城市/基地级；某些事件原始档案只给出"墨西哥湾"等大范围地区。
  • 事件密度低估：FBI 自由文本备忘录中的部分按日期记述未自动捕获； 每个文件实际可能含更多事件。
  • 翻译：英文标题为 OCR 还原后的截取，可能有 OCR 错误；详情页提供完整原档 PDF 供核对。
